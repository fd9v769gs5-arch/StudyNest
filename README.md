# 🌿 StudyNest

**Your cozy space to study, organize, and grow.**

StudyNest is a student productivity web application designed to help students organize assignments, manage study sessions, track progress, and build better study habits.

Planned Features

-  **Study Planner** — Organize subjects and assignments.
-  **Task Manager** — Create, edit, and complete tasks.
-  **Focus Timer** — Stay focused during study sessions.
-  **Progress Tracker** — Monitor your productivity.
-  **User Authentication** — Create an account and log in.
-  **Database** — Save tasks and study progress.

Tech Stack

- **Frontend:** React
- **Backend:** Node.js and Express
- **Database:** PostgreSQL
- **Version Control:** Git and GitHub

Project Status

StudyNest is currently in development. Features will be added and improved as the project grows.

Goal

To create a simple, welcoming, and useful study space that helps students stay organized and achieve their academic goals.
